# 其他週動畫評估與互動改造

評估基準：2026-10-14 已部署的 `e2728e0`；製作與測試跨至 2026-10-15（Asia/Taipei）。W02 已完成互動改造；W09/W18 是考試週。本次範圍為其他 15 個教學週。

## 有證據的結論

15 支舊影片都有生化概念與旁白，不能說完全沒有教學功能。但動畫入口都只提供原生影片播放／暫停與下載；沒有學生預測、條件輸入、與動畫相連的概念檢核或答錯回饋。因此以本次「可學習、可驗證的互動模擬」要求，15 週均需改造。這是介面與內容審查，不是已測得學生學習成效。

## 新版六幕

每週都是「預測 → 比較 → 機制 → 改條件 → 找界線 → 應用」，但使用各週不同的模型。每幕一個觀看任務；數字／圖像、反應事件與文字字幕共用可暫停的時間函數。預測不先公布答案；觀察後須回答原因，答錯可重試。改條件會清除本幕已回答狀態，重新觀察才可前進。條件相關問題與回饋會同步改變。最後兩題是新情境的形成性評量。

新版共 15×6 = 90 幕，保留已部署的 W02 六幕。只挑各週一個核心因果目標，不取代整份講義與其他課堂練習。使用繁中短句與少量英／越南詞彙，同步文字字幕；沒有新增配音或 MP4。初次測試為功能與科學模型驗證，尚未實測真人學習成效或 Safari／iOS。

## 科學界線與查證

- W01 不把葡萄糖直接改名成 ATP；分開說明物質路徑與能量轉移。
- W03 的中性官能基與水釋出是形式縮合圖；細胞蛋白合成需要其他活化與核糖體步驟。
- W04 一般變性不等於蛋白酶水解；變性可逆性不一概而論。
- W05 Hill 曲線與結合百分比是定性示意，不是人體校準值。
- W06 橫軸是反應座標；酵素不改 ΔG 或平衡位置。
- W07 使用任意模型單位的米氏公式；非競爭情境限定「純非競爭」，Km 不普遍等於親和力。
- W08 圖示不是精確 α／β 原子構型；加入纖維素酶是假設，不能解讀為人體自身能力。
- W10 只畫特定路徑的淨運輸；不宣稱粒子只向一邊走或所有主動運輸直接用 ATP。
- W11 主鏈共價連接與股間氫鍵不同；RNA 使用 U 不代表所有 RNA 為雙股。
- W12 須真正耦合；ΔG 為假設值，不能套成細胞內 ATP 的固定值。
- W13 只計糖解；乳酸發酵再生 NAD⁺，不另增加 ATP。
- W14 只計 TCA，不含丙酮酸氧化；總碳數不等於個別碳原子來源追蹤。
- W15 無氧情境等待原有梯度消散；解偶聯下電子傳遞未必立即停止。不用圖上 H⁺ 個數計 ATP 產率。
- W16 限偶數碳飽和直鏈；不包含活化成本與完整 ATP 產率。
- W17 肌肝醣主要自用；長期空腹腦可增加用酮體，仍需葡萄糖。本圖不是個人醫療或飲食建議。

科學來源記錄在各週 `learning-storyboard.json` 的 `sources` 欄與學生端「模型範圍與來源」。主要查閱 OpenStax Biology 2e 的蛋白質、酵素、膜運輸、核酸與代謝章，以及 NCBI Bookshelf 氧運輸、酵素實驗方法與酮體代謝教材。NCBI 部分頁面全文遇到驗證攔截，該部分以搜尋可見段落與既有課程核對，不聲稱全文逐句查證。未引入新臨床門檻數字。

## 本機驗收結果（2026-10-15）

- 15 週 × 桌面／手機 = 30 次完整六幕流程通過。
- 73 項獨立算術與模型性質通過，包括碳守恆、米氏半最大速率、低 pH 氧結合變化、ATP 收支與 TCA 盤點。
- 92 項介面／入口檢查通過：42 種條件全部可操作，題目與回饋跟隨條件；320px 直式與 844px 橫式沒有水平溢出；動畫總覽 16 個實驗室且零舊影片；所有課程入口正常，完整作答可返回課程；離線單檔預覽可開啟。
- 16 週 Reveal 手機橫式入口均以原生寬度顯示，不把中文縮成小字。
- W02 原有 16 項操作／同步檢查通過。新模型沒有相關 JavaScript 執行錯誤；截圖已檢視。
- 預測畫面先隱藏計算結果；條件幕「重設本幕」會清除回答與回復起始條件。字幕與模型一起暫停。

驗證環境為 Windows 上的既有 Playwright／Edge，Browser plugin 未列在本次環境。桌面 1280×900；手機 390×844、320×740；橫式 844×390。未新增瀏覽器相依套件。仍未實測 Safari／iOS 或真人學習成效。

## 建置與部署

內容與分鏡：`site/assets/animations/learning-labs/content.js`。
模型與條件相關檢核：`models.js`。播放／暫停、預測、重試、重設：`engine.js`。
每週 wrapper 與完整分鏡 JSON 由 `node tools/build_learning_labs.cjs` 產生；三個網站入口由 `python -X utf8 tools/embed_weekly_animations.py` 整合。保持既有 Reveal `#/animation`；新增 `#/learning-return` 返回本週內容。W02 使用其原來的實作與 `#/blood`。

合併 `main` 後由既有 Pages workflow 部署。旧影片入口與過期資產從公開網站移除，避免學生進入兩種不同版本；Git 歷史仍可回溯原製作證據。
