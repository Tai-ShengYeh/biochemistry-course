# 繪圖標號修正 — 執行說明

## 問題(規格 v1 的錯)

原始繪圖規格寫「**數字標號直接壓在構造上、不要拉引線**」。這條規則錯了:

- 對「大構造」(細胞核、器官)沒問題;
- 但對「小構造」(膽固醇、O₂、氫鍵、膜蛋白)和「密集圖」(電子傳遞鏈、尿素循環),
  紅色圓標會**直接蓋住它要指的東西** —— 學生反而看不到那個構造。

自動偵測:31 張圖中有 26 張的標號有遮圖問題(只有純曲線圖倖免)。

## 為什麼不叫 Codex「P 圖」

這些圖不是手繪死圖,是 `build_redrawn_assets.py` **程式生成**的:
底圖(在 `C:\Users\USER\.codex\generated_images\019f6b2b-.../`)是原始檔,
標號是程式用座標畫上去的。所以正確的修法是**改腳本、重跑**,不是對 PNG 做點陣編輯。
P 圖會有三個風險:破壞 clean/labeled 的像素一致性、可能改到已驗證正確的科學內容、
被標號蓋住的底圖區域根本不存在、無法補回。改腳本則完全避開這些。

## 修正版做了什麼(`build_redrawn_assets_v2.py`)

1. **座標改當「錨點」**:ITEMS 裡的座標不再是圓標位置,而是「要指的構造」位置。
2. **自動避讓**:`add_markers()` 會在錨點附近掃描一塊純背景空白,把圓標放那裡,
   再拉一條細引線(2px 灰)回到錨點。**圓標永不覆蓋任何繪製內容**。
3. **圓標縮小**:半徑 28 → 17。
4. **所有圖都輸出 clean 版**:原本 14 張缺 clean 的,直接從底圖生成(免修補)。
5. **底圖一個像素都不動** → clean 與 labeled 除標號/引線外完全相同,是建構上保證的。
6. **自我檢查**:結尾列出哪些標號在密集圖找不到空白(需人工微調座標)。
   已在 ETC(5 標號)、膜、ΔG 等最難的圖上實測,**零退置警告**。

## 怎麼執行

底圖 GEN 資料夾在你本機,所以要在你的電腦上跑(不是在這個雲端環境)。二擇一:

**A. 直接跑(最簡單)**
```bash
cd D:\course\biochemistry
python tools\build_redrawn_assets_v2.py
```

**B. 交給 Codex CLI 跑並驗收**
```bash
cd D:\course\biochemistry
codex exec "執行 tools/build_redrawn_assets_v2.py。完成後,對 assets/redrawn 裡每一對 *_clean.png 與 *_labeled.png 逐像素比對:差異區塊數應等於 marker_count、且每個標號中心 18px 範圍在 clean 版上必須是背景(#FDF8E8)。列出任何不符的圖。"
```

跑完會重新生成 assets/redrawn 裡全部 62 張 PNG(31 clean + 31 labeled)。

## 跑完之後

圖檔更新後,講義與投影片會自動用到新圖 —— 但需要重新產生一次 .docx / .pptx。
這一步在雲端這邊做:跟我說「圖修好了,重出講義投影片」,我會重跑全部 16 週的檔案,
新的大圖 + 乾淨標號就會進到每一份裡。

## 驗收標準(我這邊會執行)

```
每對 clean / labeled:
  差異區塊數 = marker_count
  差異區塊都落在標號/引線位置
  其餘像素完全相同(證明底圖沒被重繪)
  每個標號中心 18px 內,clean 版必須是背景(證明沒壓到構造)  ← 這次的重點
```

## 一個小提醒

錨點座標沿用 v1 的標號位置,大多正好落在正確構造上,引線也指得準。
若個別標號的引線指到構造的鄰近部位(例:指到磷脂尾而非磷脂頭),
微調 ITEMS 裡那一個座標即可 —— 那是一個數字的事,不需重畫。
