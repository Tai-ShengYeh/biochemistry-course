等電點 pI

Điểm đẳng điện

pI = 淨電荷剛好 0 的那個 pH
發生什麼 淨電荷
pH < pI 抓比較多 H⁺ 帶正電 → 往負極跑
pH = pI 正負剛好抵銷 不動
pH > pI 放掉比較多 H⁺ 帶負電 → 往正極跑

這就是電泳(điện di)的原理。用來分離蛋白質。

指令:請看關鍵句。 白板:pI 是淨電荷剛好 0 的那個 pH。 提問:pH 等於 pI 時,蛋白質會動嗎?
