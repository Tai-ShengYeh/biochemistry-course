# 生物化學課程教材 Biochemistry Course

18 週生物化學課程的完整教材,兩個版本:

| 版本 | 對象 | 特色 |
|---|---|---|
| **A · 越南學生班** | 中文 CEFR A2(約 HSK 2–3) | 中文為主,術語附越南語+英文;句長 ≤12 字;評量以標圖為主 |
| **B · 台灣學生班** | 母語者、大學部 | 正規深度,含機轉推導、自由能計算、臨床連結 |

## 行事曆

第 1–8 週上課 · **第 9 週期中考** · 第 10–17 週上課 · **第 18 週期末考**

## 用法

投影片用 [reveal.js](https://revealjs.com/) 製作,直接用瀏覽器開:

- 方向鍵 / 空白鍵:翻頁
- `S`:演講者模式(含備忘稿)
- `F`:全螢幕 · `Esc`:總覽
- `?`:快速鍵說明

GitHub Pages 首頁:`index.html`

## 結構

```
site/
├── index.html          # 首頁,列出所有週次
├── assets/
│   ├── css/course.css  # 兩套課程共用主題
│   └── figures/        # 圖檔(web 最佳化,3.7 MB)
├── vi-a2/              # A · 越南學生班
└── tw/                 # B · 台灣學生班
```

## 圖片

全部原創繪製,不臨摹任何教科書圖片。原始 PNG(1672×941)另存於 `assets/redrawn/`;
此處為 web 最佳化版(長邊 1400px JPEG,39.5 MB → 3.7 MB)。

## 授權

教材內容供教學使用。內容參考 Lehninger Principles of Biochemistry(Nelson & Cox)確認科學正確性。
