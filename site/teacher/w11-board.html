講課①：核苷酸的三個部分、核苷 vs 核苷酸

鹼基＋醣＝核苷；核苷＋磷酸＝核苷酸
10:00
白板公式（三語）
核苷 Nucleoside
鹼基 ＋ 醣
核苷酸 Nucleotide
鹼基 ＋ 醣 ＋ 磷酸
差別
只差一個磷酸
  1. 16–21　核苷酸三部分：含氮鹼基、五碳醣、磷酸（接在 5 號碳）→ 小問題：核苷酸的三個部分是鹼基、醣和什麼？（答：磷酸）
  2. 21–26　核苷 vs 核苷酸 → 小問題：一個分子只有鹼基和醣，沒有磷酸，叫什麼？（答：核苷）
  3. 小問題一律：先自己比手指 → 再公布；錯的人多就停下來再講一次
  4. 補一句：這週的 base 是「鹼基」，不是酸鹼的「鹼」
w11 投影片 ↗手寫動畫：核苷酸 ↗
26–34 分

嘌呤與嘧啶：站坐分類

嘌呤（雙環）＝ A、G；嘧啶（單環）＝ C、T、U
08:00
  1. 2 分鐘講：嘌呤兩個環、嘧啶一個環（白板畫兩個圈 vs 一個圈）
  2. 站坐題：老師念一個鹼基，嘌呤站起來、嘧啶坐著（Purine: đứng lên／Pyrimidine: ngồi）
  3. 順序：A → C → G → T → U → G → C，越念越快
  4. 最後問：「哪一個只有 RNA 有？」（答：U 尿嘧啶）
34–42 分

標圖①：核苷酸結構

對應期末題型 W11-E02；投影標號圖，比手指作答
08:00
  1. 投影核苷酸標號圖，詞庫四個：1 磷酸　2 去氧核糖　3 含氮鹼基　4 核苷
  2. 依序問「標號 3 是什麼？」「標號 1 是什麼？」→ 比手指 1–4
  3. 答案：①磷酸 ②去氧核糖 ③含氮鹼基 ④核苷（右邊紫色那塊，沒有磷酸）
  4. 錯最多的那個標號，請一位答對的學生上來用手指

講課②：雙螺旋、鹼基配對、反平行

A 配 T（兩個氫鍵）、G 配 C（三個氫鍵）；兩股方向相反
10:00
  1. 55–60　雙螺旋＋鹼基配對 → 小問題：哪一個配對正確？ 1 T—G　2 A—T　3 G—U　4 A—C（答：2，期末題型 W11-E03）
  2. 60–65　反平行：一股 5′→3′，另一股 3′→5′（雙手比：一手指上、一手指下）→ 小問題：DNA 兩股方向相同嗎？（答：不同，反平行）
  3. 回扣開場題：「為什麼 G–C 多的 DNA 比較耐熱？」→ 氫鍵比較多
  4. 看到有人精神不好，就改成站坐題：念一句話，「對」站起來、「錯」坐著（Đúng: đứng lên／Sai: ngồi）
